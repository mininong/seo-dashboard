# Natthaya Sonthinen — LASIK Marketing portfolio

Rebuilt from the supplied Thai and English ten-page portfolio PDFs.

## Pages
- index.html: Thai
- en.html: English
- style.css: responsive styling
- assets/: original portrait and seven evidence images extracted from the PDFs

Buildless static website. No dependencies, external fonts, trackers or JavaScript. Language links and expandable evidence work natively.

## Evidence mapping
Profile/contact: page 1. Role fit and SEM experience: page 2. Employment/capabilities: page 3. August vs July 2026 metrics: page 4. Search intent: page 5. Content QA: page 6. Titles, canonical/redirect, sitemap: page 7. JSON-LD, routing, SWR, noindex: page 8. Working model: page 9. Proposed 90-day plan: page 10.

Sources: Natthaya_Portfolio_LASIK_Marketing_TH.pdf and Natthaya_Portfolio_LASIK_Marketing_EN.pdf. Images are extracted from those PDFs, not new production checks. The separate original BEH technical document was not supplied this turn. Results are attributed to the portfolio and embedded evidence. Site-wide SEO metrics are not LASIK-only results or proof of individual causal impact. Contacts are events, not appointments. SWR figures are recorded server response times, not full page-load times. The 90-day plan is proposed work.
